# homebrew-apps

[Homebrew](https://brew.sh/) tap for [mikuta0407](https://github.com/mikuta0407)'s apps.

## Available formulae

### `edit`

A text editor — [mikuta0407's fork](https://github.com/mikuta0407/edit) of
[Microsoft Edit](https://github.com/microsoft/edit).

```sh
brew install mikuta0407/apps/edit
```

or:

```sh
brew tap mikuta0407/apps
brew install edit
```

Supported platforms: macOS (Apple Silicon), Linux (x86_64 / arm64).

## How releases are published

The formula is updated automatically by a workflow in the
[`mikuta0407/edit`](https://github.com/mikuta0407/edit) repository whenever a new release is
published. Pre-release tags ending in `-rc.<number>` are **not** reflected here; only regular
(latest) releases are.
